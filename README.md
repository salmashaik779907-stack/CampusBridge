# CampusBridge

## AI-Powered Smart Campus Issue Management System

CampusBridge is a college issue-management system that helps faculty and staff report campus problems and allows administrators to assign, track, and resolve them.

## Main Workflow

Faculty/Staff
↓
Create Ticket
↓
AI Suggests Category, Department and Priority
↓
Human Verification
↓
Ticket Created
↓
Admin Assignment
↓
In Progress
↓
Completed

If the due date passes before completion:

Ticket
↓
Overdue
↓
Admin / Principal Notification
